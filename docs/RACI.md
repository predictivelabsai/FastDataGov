# Delivery and operating RACI

R = responsible, A = accountable, C = consulted, I = informed. Role names are generic and can be mapped to local titles.

| Activity | Executive sponsor | Governance lead | Data owner | Data steward | Platform admin/engineer | FastDataGov implementation team |
|---|---|---|---|---|---|---|
| Pilot outcomes and funding | A | R | C | C | C | C |
| Governance operating model | I | A/R | C | C | C | C |
| Domain and product ownership | I | C | A/R | R | I | C |
| Glossary and metadata enrichment | I | A | C | R | C | C |
| Quality expectations and thresholds | I | C | A | R | C | C |
| Adapter credentials/network access | I | I | I | I | A/R | C |
| Source grants and identity aliases | I | C | I | I | A/R | C |
| Lineage gap review | I | C | C | R | A/R | C |
| Certification and attestation | I | A | R | C | I | C |
| Access-request decision | I | C | A/R | C | C | I |
| Production deployment/change | I | C | I | I | A/R | C |
| Security acceptance | I | C | I | I | A/R | C |
| Training and knowledge transfer | I | A | C | C | C | R |
| Hypercare and incident triage | I | A | C | C | R | R |
| Day-two service ownership | I | A | C | C | R | C/I |

The deploying organisation remains accountable for business definitions, ownership decisions, access approvals, source permissions, retention and regulatory interpretation.
